# RedXe measurement evidence

[AV touch-row adoption, 2026-09-05](av-touch-2026-09-05/README.md) retains the measurements collected while integrating
touch-sized selectors for RedXe's AV controls. These historical JSON receipts were moved byte-for-byte from DxUi.
They use a DxUi offscreen fixture and do not measure RedXe's full AV plugin or prove its hardware presentation budget.

Application-specific adoption evidence belongs in RedXe. DxUi owns its independent reusable scenarios, sample
programs and library benchmarks; application measurements cannot replace those or vice versa.

[Primary-button contrast validation](primary-high-contrast-2026-09-05/README.md) retains the original v1 fixture
evidence and complete native-suite receipts for the shared contrast correction adopted at commit 1947a5b.
[Early embedded-text diagnostics](embedded-text-v1-2026-09-05/README.md) retains the first, explicitly inconclusive
v1 input measurements. The final independent v2 comparisons belong to DxUi's measurement archive.
